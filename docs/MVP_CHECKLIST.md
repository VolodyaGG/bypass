Прогон API и Molecule выполнен на macOS с Python 3.14.7, Molecule 26.4.0 и Ansible Core 2.20.4. Для него использовался отдельный временный каталог и тестовый профиль; существующие профиль и серверные конфигурации пользователя не изменялись. Перезапуск проверен созданием нового экземпляра приложения, без перезагрузки компьютера. Чистая установка на другом компьютере и работа Python 3.11 в этом прогоне не проверялись.

Для автоматического TLS тесты подменяют удалённый Ansible и команды управления службами.
Настоящий выпуск Let's Encrypt, доступность порта 80 из интернета, системный таймер и
последующий VPN-туннель требуют отдельной проверки на VPS с действующим доменом.

## Ручная проверка перед записью видео

Эти пункты нужно пройти в браузере после установки и запуска; текущий API-прогон их не заменяет.

- [ ] Открыть `http://127.0.0.1:8000/`, войти в свой профиль.
- [x] В режиме «Демо» очистить адрес и нажать запуск: появляется понятная ошибка, фокус переходит в поле. Проверено на отдельном тестовом профиле.
- [x] Нажать «Тестовые данные», затем «Запустить демо»: видны этапы и «Симуляция завершена».
- [x] Обновить страницу: адрес, протоколы и строка «Последнее демо» восстановлены.
- [ ] Остановить и снова запустить backend, открыть тот же адрес браузера: профиль и сохранённые параметры доступны.
- [ ] Выйти, проверить неверный пароль и снова войти с правильным.
- [x] На экране шириной 360 px журнал идёт после формы; горизонтального переполнения документа нет.
- [ ] В режиме «На VPS» при Hysteria выбрать автоматический сертификат: поля PEM и путей скрыты; при переключении источника появляются соответствующие поля.
- [ ] Когда появятся VPS и домен: выполнить реальный автоматический деплой, проверить HTTPS-подписку, туннель и `certbot renew --cert-name bypass-<домен> --dry-run` на сервере.

- [ ] Видео продолжительностью меньше минуты, с показом фактической среды и модели, входа, демо и сохранённого результата.
- [ ] Передать архив исходников либо ссылку на открытый репозиторий с последними изменениями. Локально подготовленный ZIP сам по себе ещё не является отправленной работой.

В архиве должны быть исходники, lock-файл, документы и изображения референсов. Исключаются `.venv`, реальные `.env`, данные профиля и серверов, служебные каталоги и локальные экспериментальные файлы. Для реального VPN остаётся отдельный будущий прогон на VPS: учебное демо не подтверждает работоспособность туннеля.
