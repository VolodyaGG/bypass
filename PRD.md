# bypass · PRD для ИДЗ1

## Идея и пользователи

**bypass** — локальная браузерная панель для развёртывания VPN на собственном VPS. Она нужна владельцу сервера, который хочет выбрать протоколы, запустить настройку и получить конфиг подключения для клиента. Для знакомства с панелью есть учебный сценарий с тестовыми данными.

Пользователь заполняет одну форму. В режиме «На VPS» bypass запускает Ansible на выбранном VPS. В режиме «Демо» Molecule выполняет тестовый сценарий на localhost. Оба режима используют общий экран запуска и журнал.

## Функции

| Функция | Что получает пользователь | Состояние |
| --- | --- | --- |
| Настройки запуска | Указывает сервер, выбирает Hysteria 2, VLESS Reality или OpenFlux и заполняет поля выбранного протокола | Одна форма с переключателем режима и отдельными значениями для каждого режима |
| Запуск в двух режимах | Проверяет сценарий на тестовых данных или разворачивает VPN на своём сервере | Форма подключена к отдельному API для каждого режима |
| Журнал и результат | Видит события запуска, итоговый статус и причину ошибки | Оба режима подключены к общему журналу |
| Клиенты и конфиги | После реального деплоя управляет клиентами, копирует ссылку подписки или скачивает Xray JSON | Работает в существующей панели |
| Локальный профиль | Входит по имени и паролю и после перезапуска видит сохранённые параметры и результат прогона | Отдельная страница входа и запись демо в браузере |

## Основной сценарий для сдачи

1. Пользователь запускает bypass на компьютере, открывает главную страницу и входит по имени и паролю. При первом запуске создаёт локальный профиль.
2. В панели выбирает «Демо», указывает адрес `203.0.113.10`, включает Hysteria 2 и вводит тестовые значения. Кнопка «Тестовые данные» заполняет пример автоматически. Если обязательное поле пустое, панель показывает ошибку и переводит фокус к этому полю.
3. Нажимает «Запустить демо». Форма отправляет запрос на `POST /api/deploy/demo` и открывает журнал по полученному `job_id`.
4. В журнале последовательно появляются создание тестового описания деплоя, повторный прогон без изменений и проверка результата. При сбое журнал остаётся доступным, а панель показывает причину и даёт повторить запуск.
5. Панель показывает «Симуляция завершена». Пользователь обновляет страницу или перезапускает приложение и видит сохранённые настройки и последний результат.

Инструкция локального запуска, шаги проверки в браузере и пример API с `curl` есть в [README.md](README.md).

## Технические решения и данные

- **Приложение.** Python, FastAPI, Jinja2, обычный JavaScript и CSS. Локальный запуск на `127.0.0.1:8000` через Uvicorn.
- **Выполнение.** Реальный деплой использует Ansible и SSH. Демо запускает `molecule test` в отдельном временном каталоге. В демосценарий попадают только адрес, домен, тип окружения и протоколы. Molecule проверяет локальный JSON, а временный каталог удаляется после завершения.
- **Журнал.** Оба режима возвращают `job_id` и передают логи через `GET /api/deploy/stream/{job_id}` с помощью SSE. Текущие задания и их события хранятся в памяти приложения.
- **Хранение реального деплоя.** Настройки серверов и клиенты хранятся в локальных JSON-файлах, по умолчанию в `data/secrets/`. Форма хранит настройки окружения в браузере. Новые записи исключают пароли, токены Cloudflare и ключ шифрования OpenFlux.
- **Хранение демо.** В `localStorage` для каждого учебного имени сохраняются адрес, домен, протоколы, тип окружения, дата и статус последнего запуска. Запись строится из явного списка полей. Данные доступны в том же браузере по тому же локальному адресу. Очистка данных сайта удаляет записи.
- **Локальный вход.** На одну директорию данных создаётся один профиль. Сервер хранит хеш пароля scrypt с уникальной солью в `data/auth/auth.sqlite3`. Cookie содержит случайный токен сессии со сроком семь дней. Панель и управляющие API требуют действующей сессии, которую сервер отзывает при выходе.

В проверку итоговой версии входят успешный прогон, ошибка с возможностью повторного запуска и восстановление данных в том же браузере. Публичный хостинг, PWA и управление несколькими пользователями оставляем за рамками проекта.
