# bypass · Дизайн интерфейса

## Направление

У **bypass** одна панель для настройки VPN и просмотра результата. Режим запуска выбирается рядом с основной кнопкой. При смене режима форма сохраняет введённые значения, а журнал явно показывает, какой запуск открыт.

**Референс** — [скриншот Railway Build Logs](https://res.cloudinary.com/railway/image/upload/v1722993947/docs/build_logs_og7uec.png). Из Railway взята компоновка с отдельной областью журнала. Шапка, форма входа и журнал используют Liquid Glass. Блоки настроек лежат на общем фоне и разделены линиями.

## Компоновка

| Область | Содержимое |
| --- | --- |
| Страница входа | Слева заголовок и линия маршрута, справа форма с именем и паролем. При первом запуске добавляется повтор пароля. На узком экране форма идёт под заголовком |
| Шапка | Авторский знак в форме строчной `b` с ответвлением маршрута, название `bypass`, помощь, имя профиля и кнопка «Выйти». Тот же знак используется во вкладке и в схеме на входе |
| Настройки | Адрес сервера, SSH, протоколы. DNS, TLS, маршрутизация и параметры OpenFlux раскрываются по необходимости |
| Запуск | Одна строка с вкладками «Демо / На VPS», описанием режима и кнопкой «Запустить демо» или «Развернуть на VPS». Линия рядом с заголовком показывает выбранную цель, localhost или VPS по SSH |
| Журнал | Название режима, текущий этап, вывод Ansible или Molecule и итог. На широком экране находится справа от формы, на узком идёт после блока запуска |
| Клиенты | Список клиентов и действия «Копировать подписку» и «Скачать Xray JSON» для реального сервера |

## Компоненты

В проект локально включена таблица стилей **Bootstrap 4.5.0**. Страница входа и панель используют `form-control`, `btn-group`, `card`, `badge` и `alert` с цветами bypass. Свёрнутые разделы используют HTML-элемент `details`, журнал и поток событий реализованы в приложении.

## Состояния запуска

| Состояние | Что видит пользователь |
| --- | --- |
| Ожидание | Поля формы доступны. Журнал показывает подсказку «Логи появятся после запуска» |
| Ошибка формы | Проблемное поле выделено, рядом написано, что исправить. Фокус переходит к первому проблемному полю |
| Идёт запуск | Видны режим, текущий этап и новые строки журнала. Повторное нажатие на запуск заблокировано |
| Успех | Для демо отображается «Симуляция завершена». Для реального запуска отображается «Сервер настроен» и становятся доступны действия с клиентами |
| Ошибка запуска | Видны причина и журнал. Введённые поля сохраняются для повторной попытки |
| Отмена демо | Журнал остаётся на экране со статусом «Запуск отменён» |
